💡 Conceitos Implementados & Resumo dos Exercícios

A classe Funcionario encapsula os atributos privados _id, _nome, _idade, _cargo e _salario. Foram definidos métodos de acesso (get e set) com validação de dados para garantir integridade e o método toString() formatado.

Demonstração prática da substituição de funções anônimas clássicas por arrow functions na manipulação do array de funcionários:

// 1. Função Anônima Tradicional (Ex: busca por ID):
const buscarTradicional = function(id) {
    return funcionarios.find(function(f) {
        return f.id === id;
    });
};

// 2. Substituída por Expressão Lambda / Arrow Function:
const buscarPorId = (id) => funcionarios.find((f) => f.id === id);

// Vantagens: sintaxe concisa, retorno implícito e escopo léxico de 'this'.
// 1. Salário > R$ 5.000:
const maioresQue5000 = funcionarios.filter((f) => f.salario > 5000);

// 2. Média Salarial com reduce:
const media = funcionarios.reduce((acc, f) => acc + f.salario, 0) / funcionarios.length;

// 3. Cargos únicos sem repetição com new Set():
const cargosUnicos = [...new Set(funcionarios.map((f) => f.cargo))];

// 4. Nomes em caixa alta com map():
const nomesMaiusculos = funcionarios.map((f) => f.nome.toUpperCase());
